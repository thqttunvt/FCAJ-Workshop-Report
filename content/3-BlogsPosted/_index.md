### Published Blog Articles

* **[Blog 1: If an Intruder Can Delete the Logs, What Is Left to Investigate With?](3.1-blog1/)** · [AWS Study Group Post](https://www.facebook.com/groups/awsstudygroupfcj/posts/2330733614358264)

* **[Blog 2: Passwords in Source Code: Convenient Once, Costly Many Times](3.2-blog2/)** · [AWS Study Group Post](https://www.facebook.com/groups/awsstudygroupfcj/posts/2331503327614626)  
  Eliminating hardcoded credentials and managing the secret lifecycle on AWS with AWS Secrets Manager, AWS KMS, least-privilege IAM roles, and AWS CloudTrail.

* **[Blog 3: A Public API Doesn't Mean Anyone Can Call It as Often as They Want](3.3-blog3/)** · [AWS Study Group Post](https://www.facebook.com/groups/awsstudygroupfcj/posts/2339564356808523)  
  Protecting public APIs from request floods and abuse with AWS WAF rate-based rules, managed rule groups, Amazon API Gateway authorizers, and Amazon CloudWatch monitoring.
